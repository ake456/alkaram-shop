# الكرم | Al Karam Shop

متجر إلكتروني متجاوب ثنائي اللغة، مستلهم من المواد المرجعية المرفقة، ويعتمد على بيانات الفئات والمنتجات من [DummyJSON](https://dummyjson.com/products/category/).

## المزايا

- واجهة عربية/إنجليزية مع دعم RTL وLTR.
- وضع نهاري ووضع ليلي مع حفظ التفضيل محليًا.
- منتجات وفئات حية من DummyJSON مع بيانات بديلة عند تعذّر الاتصال.
- بحث، فلاتر فئات، تفاصيل منتج، وسلة تسوق تحفظ محتواها محليًا.
- تدفق تأكيد طلب مراجعة بدفع عند الاستلام بدون بوابة دفع إلكترونية.
- صفحة تواصل كاملة مع تحقق من الحقول.
- تصميم متجاوب للجوال واللوحي والكمبيوتر.

## التشغيل محليًا

```bash
pnpm install
pnpm dev
```

يفتح الموقع على المنفذ `3000`.

## بناء نسخة الإنتاج

```bash
pnpm build
```

تُنشأ نسخة الإنتاج داخل مجلد `dist`.
